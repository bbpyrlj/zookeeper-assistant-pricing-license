## 条款里的几个细节，买之前值得看清楚

设备数的限制指的是“同时激活”。条款写的是一个用户最多两台机器同时在线，所以换电脑不用重新买，只要别让第三台同时挂着。笔记本加台式机刚好用满额度，再添一台办公机就得再买一份。

升级这一条明确写的是免费升级。大版本更新要不要再掏钱，在这个产品上已经有了答案，这一点在买断制工具里算厚道。如果你以前吃过“买断小版本、大版本另收费”的亏，这次不用担心。

退款窗口是 7 天。官网下单的订单由 Paddle 处理，Paddle 是 Merchant of Record，退款也走 Paddle。在荔枝下单的话，售后归荔枝，退款条件要看它商品页的说明或直接问客服，别默认和官网一模一样。

技术支持方面，官方有独立的支持站点，条款里没有给支持服务设期限，也没有写“只服务第一年”这类限制。

授权范围包括商业用途。公司在内部使用不需要另外买商业授权，前提是人数和机器数都在授权范围内。

还有一条不算坑但值得提醒：这是个给运维和排障用的图形客户端。如果你的日常工作是写业务代码，很少直接碰 ZooKeeper 的节点结构，它帮不上你什么，装上也只会多一个要更新的软件。

## 常见问题

**荔枝上买的是永久授权吗？**
官方条款里这份授权没有到期时间，并且包含免费升级，所谓永久就是这两条。荔枝页面对授权类型的标注，下单前对一眼。

**一份授权能装几台电脑？换电脑要重新买吗？**
一个用户同时最多两台。换电脑不用重新买，条款限制的是同时激活的数量，不是把授权焊死在某台机器上。

**大版本升级要另外加钱吗？**
官方购买页写的是免费升级。

**买了不合适能退吗？**
官网下单 7 天内可退，走 Paddle；荔枝渠道按荔枝的售后规则来，下单前问一句更稳。

**有功能受限的免费版吗？**
没有免费版和付费版的功能差异，但可以先免费评估再决定买不买授权码。
